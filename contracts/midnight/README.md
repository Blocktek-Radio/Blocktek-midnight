# Midnight Contract Boundary

This directory is reserved for the first real Compact contract, covering contributor eligibility and selective disclosure.

No contract is claimed to be deployed here. The current API uses `UnconfiguredMidnightAdapter` and reports `MIDNIGHT INTEGRATION: NOT CONFIGURED`. A real implementation must be added only after the Midnight SDK, Compact compiler, target network, node, and indexer are pinned and available in the build environment.

The first contract should prove an eligibility predicate without publishing private identity attributes. Audio, evidence files, streams, and AI jobs remain off-chain.
